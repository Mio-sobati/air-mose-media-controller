# کنترلر مدیا و ایرماوس با ESP32-C3 (Air Mouse & Media Controller)

یک کنترلر مدیا و ایرماوس بلوتوثی سخت‌افزاری و جامع. این پروژه بر پایه میکروکنترلر **ESP32-C3** (معماری RISC-V) ساخته شده و از سنسور ژیروسکوپ **GY-25** برای ردیابی حرکت، یک روتاری انکودر برای تنظیمات پویا، و یک آرایه از دکمه‌های آنالوگ برای دستورات ورودی استفاده می‌کند.

این دستگاه به عنوان یک دستگاه استاندارد بلوتوثی HID (Human Interface Device) عمل می‌کند. هیچ نیازی به نصب اپلیکیشن یا درایور خاصی روی دستگاه مقصد ندارد و مستقیماً روی اندروید، iOS، ویندوز، مک و تلویزیون‌های هوشمند کار می‌کند.

## 🚀 ویژگی‌های کلیدی و منطق عملکرد

- **حالت ۱ (ال‌ای‌دی سبز): ایرماوس (Air Mouse)**
  - **ردیابی حرکت:** خواندن زوایای خام Yaw و Pitch از سنسور GY-25 از طریق پورت سریال سخت‌افزاری.
  - **فیلتر نرمی و شتاب (Smoothing & Acceleration):** اعمال فیلتر نمایی نرم‌افزاری و ضریب شتاب پویا. هرچه دست خود را سریع‌تر حرکت دهید، نشانگر (کرسر) مسافت بیشتری را طی می‌کند (شبیه‌سازی ماوس‌های حرفه‌ای).
  - **کلیک و اسکرول:** کلیک چپ/راست و اسکرول بالا/پایین به دکمه‌های فشاری آنالوگ متصل شده‌اند.
  - **تنظیم حساسیت در لحظه:** فشردن دکمه روتاری انکودر حالت تنظیم حساسیت را فعال/غیرفعال می‌کند و چرخاندن آن سرعت پایه کرسر را در لحظه تغییر می‌دهد.

- **حالت ۲ (ال‌ای‌دی بنفش): ریموت مدیا (Media Remote)**
  - **کنترل ولوم صدا:** چرخش روتاری انکودر مستقیماً به افزایش و کاهش صدا (Volume Up/Down) تبدیل می‌شود.
  - **پخش رسانه:** دکمه‌ها برای دستورات پخش/توقف (Play/Pause)، آهنگ بعدی و آهنگ قبلی استفاده می‌شوند.

- **راهکار حل مشکل "دو پروفایل" (Identity Fix):**
  اتصال یک دستگاه بلوتوث واحد که سعی دارد همزمان هم ماوس و هم کیبورد مدیا باشد، معمولاً باعث مشکل کش (Cache) و تداخل در سیستم‌عامل می‌شود. این پروژه با تغییر جزئی و مجازی MAC Address داخلی ESP32 در هنگام ورود به حالت مدیا، این مشکل را حل می‌کند. سیستم میزبان دو دستگاه فیزیکی کاملاً مجزا (`Air Mouse ESP` و `Air Media ESP`) را می‌بیند که اتصالی پایدار و بدون قطعی را تضمین می‌کند.

## 🐛 باگ‌ها و مشکلات شناخته‌شده

- **مشکل کنترل مدیا در اندروید:** در حال حاضر، حالت **کنترلر مدیا** (ال‌ای‌دی بنفش) روی دستگاه‌های اندرویدی **کار نمی‌کند**. با وجود برقراری اتصال، دستورات مدیا (ولوم، پخش/توقف، تغییر آهنگ) ممکن است توسط سیستم‌عامل اندروید دریافت و اجرا نشوند. حالت ماوس روی اندروید بدون نقص کار می‌کند و حالت مدیا نیز روی ویندوز و iOS رفتار نرمالی دارد. ما در حال بررسی و رفع این مشکل در پروفایل HID برای اندروید هستیم.

## 🔌 اتصالات سخت‌افزاری (سیم‌کشی ESP32-C3)

| قطعه (Component) | پین قطعه | پین ESP32-C3 | توضیحات / عملکرد |
| :--- | :--- | :--- | :--- |
| **سنسور ژیروسکوپ GY-25** | `TX` | `GPIO 2` | Serial RX برای ESP32 |
| | `RX` | `GPIO 3` | Serial TX برای ESP32 |
| | `VCC` / `GND` | `3.3V` / `GND` | تغذیه (نیاز به ارتباط UART با بادریت 115200) |
| **روتاری انکودر** | `CLK` | `GPIO 6` | تنظیم حساسیت / ولوم |
| | `DT` | `GPIO 7` | تشخیص جهت چرخش |
| | `SW` | `GPIO 10` | دکمه فشاری (سوئیچ حالت حساسیت) |
| | `+` / `GND` | `3.3V` / `GND` | تغذیه |
| **دکمه تغییر حالت (Mode Switch)** | `Button Pin` | `GPIO 4` | جابه‌جایی بین حالت‌های ماوس و مدیا (Pull to GND) |
| **دکمه‌های آنالوگ** | `Output` | `GPIO 0` | مقسم ولتاژ شبکه‌ای مقاومتی (ADC) |
| **ال‌ای‌دی WS2812 NeoPixel** | `DIN` | `GPIO 5` | نشانگر وضعیت (سبز/بنفش) |

*(نکته: از پین‌های GPIO 8 و 9 برای ورودی‌های حیاتی روی ESP32-C3 استفاده نکنید، زیرا این پین‌ها Strapping هستند و می‌توانند در فرآیند بوت اختلال ایجاد کنند).*

## 🎛️ نحوه کارکرد شبکه دکمه‌های آنالوگ (Analog Button Array)
برای صرفه‌جویی در پین‌های GPIO میکروکنترلر ESP32-C3، هر چهار دکمه اصلی (چپ، راست، بالا، پایین) از طریق یک **شبکه مقاومت (مقسم ولتاژ)** به یک پین مبدل آنالوگ به دیجیتال (ADC) یعنی `GPIO 0` متصل شده‌اند.

وقتی دکمه‌ای فشرده می‌شود، افت ولتاژ مشخصی ایجاد می‌کند. تراشه ESP32 این ولتاژ را به عنوان عددی بین 0 تا 4095 (دقت ۱۲ بیت) می‌خواند. بسته به مقدار دقیق مقاومت‌هایی که استفاده می‌کنید (مثلاً ۱ کیلو، ۲ کیلو، ۴.۷ کیلو و ۱۰ کیلو اهم)، ممکن است نیاز باشد محدوده‌های تعریف‌شده در کد را کالیبره کنید.

محدوده‌های فعلی ADC در تابع `loop()`:
- کلیک چپ / آهنگ قبلی: `بیشتر از 3700`
- کلیک راست / آهنگ بعدی: `بین 3200 تا 3699`
- اسکرول بالا / پخش و توقف: `بین 2300 تا 3199`
- اسکرول پایین: `بین 1000 تا 2299`

## ⚙️ راه‌اندازی و نحوه استفاده

1. **آپلود کد:** فایل `.ino` را روی برد ESP32-C3 آپلود کنید.
2. **حالت ماوس:** دستگاه را روشن کنید. نئوپیکسل با رنگ سبز چشمک می‌زند تا منتظر اتصال بماند. گوشی یا کامپیوتر خود را به بلوتوث **Air Mouse ESP** متصل کنید.
3. **تغییر حالت:** دکمه تغییر حالت (متصل به پین GPIO 4) را فشار دهید. ESP32 حالت را در حافظه ماندگار (NVS) ذخیره کرده و ری‌استارت می‌شود. ال‌ای‌دی این‌بار با رنگ بنفش چشمک خواهد زد.
4. **حالت مدیا:** در این حالت، گوشی یا سیستم خود را به دستگاه بلوتوثی جدیدی به نام **Air Media ESP** متصل کنید.
5. **آماده استفاده:** حالا می‌توانید با فشردن دکمه سخت‌افزاری، به راحتی بین حالت‌های ماوس و مدیا جابه‌جا شوید. اتصال مجدد بسیار سریع و خودکار انجام می‌شود.
